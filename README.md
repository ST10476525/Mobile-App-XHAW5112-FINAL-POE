Precious Radebe Mobile app
Empowering the Nation – Mobile Application
 Skills Training for Domestic Workers & Gardeners
 Developed: 2025
 Institution: The Independent Institute of Education
 Overview
 Empowering the Nation is a mobile application developed for a South African SME founded by Precious
 Radebe. The app showcases courses, calculates quotations, and allows customers to request contact.
 Background & Business Purpose
 Established in 2022, Empowering the Nation provides skill building opportunities for domestic workers
 and gardeners in Johannesburg.
 App Features
 1. Home Page – Logo, intro, and navigation.
 2. Six Month Course Summary.
 3. Six Week Short Course Summary.
 4. Course Detail Pages.
 5. Quotation Calculator with discount logic.
 6. Contact Page with Google Maps link.
 7. Navigation via React Navigation.
 8. Professional UI design.
 9. Error handling for customer forms.
 Technologies Used
 React Native, TypeScript, React Navigation, Linking API.
 Data Model
 Six month courses: First Aid, Sewing, Landscaping, Life Skills.
 Short courses: Child Minding, Cooking, Garden Maintenance.
Fee Calculation Logic
 1 course → 0%
 2 courses → 5%
 3 courses → 10%
 4+ courses → 15%
 Navigation Structure
 Home → SixMonthSummary → CourseDetail → Quote → Invoice
 Home → ShortSummary → CourseDetail
 Home → Contact
 Home → About
 Contact Page – Map Button
 Includes button opening Google Maps for Soweto Training Centre.
 Assignment Requirements Completed
 All milestones completed including course lists, details, fee calculator, contact details, navigation, and
 UI design.
 Conclusion
 The Empowering the Nation app meets all requirements and supports the SME’s mission of community
 upliftment through skills developme
